# v1.7.0

**Release Date:** 2026-11-14  
**Theme:** Security & SSRF Remediations, Pure-SDK Parity, Operator Web UI Wiring, Helm Chart & Automated Release Packaging

---

## Security & SSRF Defense-in-Depth

- **Canonical Provider `BaseURL` & Preflight SSRF Enforcement** (`internal/adapter/`, `internal/server/`): Added canonical `ValidateAndResolveBaseURL` across native adapters (`openai`, `anthropic`, `mistral`, `ollama`, `gemini`, `azure`), `openaicompat` profiles (`ProfileRegistry` + `resolveEndpointBase`), and admin credential creation/rotation/validation handlers. Restricted private-network preflight probes to `platform_admin`, and hardened Gemini `isVertexExpressKey` to parsed hostname equality.
- **Isolated Untrusted Media Fetch Policy** (`internal/adapter/media.go`): Added `DefaultPublicMediaPolicy` and `FetchRemoteDataURIWithPolicy`, isolating end-user `image_url` and `document.url` fetches on `ollama` and `vertex` behind strict public-HTTPS `mediaPolicy` / `mediaClient` instances (`AllowPrivateNetworks: false`, `AllowInsecureHTTP: false`).
- **Response, Header & Concurrency Hardening** (`internal/server/`, `internal/auth/`, `internal/logger/`): Emitted strict `Content-Security-Policy: default-src 'none'; frame-ancestors 'none'` on non-UI routes, validated `/v1/audio/speech` `Content-Type`, sanitized `X-Request-Id` and fallback `Content-Type`, scoped `sha256.Sum256` JWT signature checks strictly to `RS256`/`ES256`, warned on short `auth.default_virtual_key` (&lt; 32 chars), streamed multipart image uploads via `io.Copy`, and fixed a response-marshal race in `handleCreateBatch`.

---

## Go SDK (`pkg/gateway`), Contracts & Streaming Telemetry

- **WebSocket Realtime & Pure-SDK Modality Wrappers** (`pkg/gateway/`): Added `ConnectRealtime` (`*RealtimeSession` with `SendEvent`, `ReadEvent`, and `Close`), `WithHTTPClient`, and zero-internal-import typed SDK methods (`CreateEmbedding`, `CreateRerank`, `CreateModeration`, `CreateResponse`, `StreamResponse`, `CreateImage`, `CreateSpeech`, `TranscribeAudio`, and `GetSpendSummary`). See the [Go SDK API Reference](/docs/sdk/go-sdk-reference).
- **`/v1` + `/admin/v1` Spec Parity & Streaming Headers** (`cmd/specgen/`, `internal/server/`): Updated `cmd/specgen` to verify both `/v1` and `/admin/v1` route parity (`63` Unified OpenAPI paths), emitted `X-Gateway-Provider` and `X-Gateway-Model` before the first SSE chunk on streaming chat completions, and exposed `X-Gateway-*` telemetry headers via CORS `Access-Control-Expose-Headers`.
- **Multi-Replica HA & Tri-State Serialization** (`internal/auth/`, `internal/storage/`, `internal/server/`): Preserved 3-state allowlists (`null` = Inherit vs `[]` = Deny All) across Redis L2 `IdentityContext`, `Team`/`VirtualKey` JSON responses, and `optionalStringSlice` patch decoding (`PATCH`/`PUT` handlers), and ensured `PostgresRepository` mutations and `TEXT[] NOT NULL` bindings stay coherent across multi-replica pods.

---

## Routing & Operator Web UI (`web/`, `internal/ui/`)

- **6th Load-Balancing Strategy (`round-robin`)** (`internal/domain/`, `internal/router/`): Added `domain.StrategyRoundRobin` (`"round-robin"`) with per-`ModelGroupID` atomic rotation in `LoadBalancer.selectRoundRobin`. See [Routing & Load Balancing](/docs/gateway/routing-and-load-balancing).
- **Control-Plane Contract Alignment**: Synced TypeScript models and views with `spent_micros`, 7 user/key roles (`platform_admin` through `service_account` / `viewer`), explicit 3-state `Inherit | Deny All | Custom List` allowlist controls, `round-robin` routing strategy, Pricing History modal, full Guardrails controls (`mode`, `scan_all_roles`, toxicity filter, content categories), `MCPTool.input_schema`, OAuth2/`static_headers` MCP config, `none | static | vault_jwt` A2A auth, inline `valid: false` credential validation errors, URL-encoded admin queries, and `&lt;ScopedRoleNotice&gt;` `403` handling across all 16 `sanitizeRuntimeConfig` sections.
- **SSE Playground & Nested SPA Assets**: Fixed SSE `event: error` detection and EOF decoder flushing, dynamically populated Playground model aliases from unlocked admin endpoints, removed empty assistant error placeholders, and switched favicon/logo assets to `/ui/*` paths within the `<= 420 KB` / `<= 125 KB` gzip bundle budget.

---

## Database Migrations (`0013`–`0015`) & Release Packaging

- **Migration `0013_user_limits_and_spend_indexes`**: Adds per-user `rpm_limit`, `tpm_limit`, `max_concurrent_requests`, `max_budget_micros`, `spent_micros`, `budget_reset_period`, and `budget_reset_at` columns to `users`, plus `(org_id, team_id)` and `(org_id, user_id)` indexes on `spend_logs`.
- **Migration `0014_budget_reset_outbox_user_scope`**: Expands `budget_reset_outbox_scope_check` to `CHECK (scope IN ('org', 'team', 'user', 'key'))`.
- **Migration `0015_team_org_concurrency`**: Adds `max_concurrent_requests` to `organizations` and `teams`.
- **Helm Chart & Automated Release Packaging** (`deployments/helm/goroute/`, `.github/workflows/release.yml`, `Makefile`): Added `make release-assets` for cross-platform archives (`darwin`/`linux`/`windows`, `amd64`/`arm64`), `checksums.txt`, Helm `.tgz` (`goroute` chart `0.2.0` / `appVersion: 1.7.0`), and Kubernetes bundle archives alongside multi-arch `ghcr.io/goroute-ai/ai-gateway-go` publishing with full OCI image labels. See [Helm Chart Deployment](/docs/deploy/helm-chart).
