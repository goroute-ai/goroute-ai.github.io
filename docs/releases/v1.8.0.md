# v1.8.0

**Release Date:** 2026-11-16  
**Theme:** Multi-Provider Guardrails Engine, 19 Built-In Drivers, Zero-Trust Tool/MCP Governance & Light Blue Dark/Light Operator Web UI

---

## Two-Layer Guardrails Engine, 19 Built-In Drivers & Tool/MCP Governance

- **Baseline Toxicity Persistence & Named Registry (`migrations/0016`, `0017`)**: Persists `GuardrailPolicy` toxicity filter and 5 content category lists in PostgreSQL alongside tenant-scoped `guardrail_definitions` (Vault AES-256-GCM encrypted secrets and DEK rotation) and hierarchical `guardrail_bindings` (`Org` → `Team` → `VirtualKey` → `EndUser` → `ModelGroup` → `Tag`, with `default_on` and anti-bypass `is_locked` enforcement).
- **Pipeline v2 Lifecycle & Load Balancing**: Supports all 7 execution hooks (`pre_call`, concurrent canceling `during_call`, `post_call`, async `logging_only`, `pre_mcp_call`, `during_mcp_call`, `post_mcp_call`), `stream_scope`, tag-based `mode_rule` routing, weighted `RouterLB` cooldown load balancing, and `goroute_extensions` (`guardrails`, `tags`) across inference, non-chat, and OpenAPI contracts (`73` Unified OpenAPI paths: `24` `/v1` + `49` `/admin/v1`).
- **Extensibility (Public Go SDK, Rich Webhooks & Starlark `custom_code`)**: Adds exported `pkg/gateway.GuardrailScanner` (`WithGuardrailScanner`, `allow`/`block`/`flag`/`modify`), rich `generic_http` webhooks with independent per-scanner timeouts and fail-open handling, and sandboxed Starlark `custom_code` scripts (`apply_guardrail`) with deterministic `50,000`-step limits, context deadlines, zero filesystem/import access, and SSRF-checked `http_get`/`http_post`.
- **19 Built-In Drivers, LLM Judges & Streaming Windowing**: Adds `openai_moderation`, `bedrock` (SigV4), `azure/prompt_shield`, `azure/text_moderations`, `model_armor`, `presidio`, `lakera_v2`, `guardrails_ai`, `pangea`, `local_content_filter`, `llm_as_a_judge`, `decision_model` (with recursion loop protection), cross-chunk `StreamWindowEvaluator` masking, and incremental streamed `delta.tool_calls` scanning.
- **Tool & Zero-Trust MCP Governance (`migrations/0018`)**: Adds rule-based `tool_permission`, persistent cross-turn `tool_policy` trust-chain taint tracking inside `ToolLoopOrchestrator`, `block_code_execution`, `mcp_security`, `mcp_end_user_permission`, and `mcp_jwt_signer` upstream token exchange.
- **Standalone Evaluation API & Micro-Dollar Telemetry (`migrations/0019`)**: Adds Data Plane `POST /v1/guardrails/apply`, expanded `/admin/v1/organizations/{orgID}/guardrails/simulate`, registry/binding/tool-policy/usage endpoints, declarative YAML seeding (`guardrails.definitions[]`, `guardrails.tool_policies[]`), scrubbed `guardrail.evaluate` OpenTelemetry spans, and `gateway_guardrail_evaluations_total`, `gateway_guardrail_errors_total`, and `gateway_guardrail_duration_ms` Prometheus metrics.

---

## Light Blue Dark & Light Operator Web UI Theme & Guardrails Console (`web/`, `internal/ui/`)

- **Dark & Light Theme System**: Adopts CSS-custom-property Obsidian Dark (`#000000` canvas, `#38bdf8` light-blue accent) and Pristine Slate Light (`#ffffff` canvas, `#0369a1` sky-blue accent) themes, backed by a CSP-compliant synchronous `ThemeContext` (`localStorage` persistence) and Header Dark/Light toggle.
- **4-Tab Guardrails Operator Console**: Adds lazy-loaded views for **Org Baseline Policy**, **Named Guardrails & Provider Registry** (including Starlark editor and tag matrix), **Tool Policies & Trust Matrix**, and **Pipeline Simulator (`/v1/guardrails/apply`) & Micro-Dollar Usage Dashboard**.
